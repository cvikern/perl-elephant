# perl-elephant

This code was made by using the lates AI models from Anthropic (Claude Fable 5.1) and Open AI (Astra in Ultra mode) as a way to explore the borders of what AI can do with code generation. The results are no less than amazing.

The old, but well known, Perl Camel Code can be found at https://gist.github.com/cgoldberg/4332167#file-camel-pl
